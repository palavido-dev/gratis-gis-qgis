description=Browse, edit, and publish GratisGIS portal content from QGIS.
about=A native QGIS integration for GratisGIS, the open source self-hosted alternative to ArcGIS Online. Browse portal items from the QGIS Browser panel, search the portal, drag data layers and maps to the canvas, publish vector layers as portal data_layer items, publish PMTiles / GeoTIFF / MBTiles as tile_layer items, push QGIS edits back to portal-backed layers, clone layers for offline use, and publish the current QGIS project as a portal map. Private and org-shared layers render on the canvas via a read-only portal API key minted at sign-in and stored in the QGIS authentication database. Auth is OAuth + PKCE against the portal's Keycloak realm. No third-party Python dependencies. Licensed under AGPL-3.0-or-later; see the bundled LICENSE file.

changelog=1.0.0 (2026-08-17) - First stable release. Browse and search portal content, add layers with working attribute tables by default (large layers render as fast tiles), open portal maps with their saved styling and viewport, publish vector layers and whole projects, push edits back, clone for offline use, share from QGIS including to groups, and run publish/clone/sync as Processing algorithms. Private content works throughout via the portal's signed-in surfaces (needs GratisGIS portal 0.9.29+). 0.16.0 (2026-08-17) - Portal layers now add as real feature layers by default, with working attribute tables, wherever the layer is small enough to load comfortably; only very large layers (over 50,000 features) stay on fast tiles, with Add with full attributes still a right-click away. Applies to the Browser, search, drag and drop, and opened maps, which also style their feature layers with the map's saved symbology. Tables referenced by a map now load their rows instead of being skipped. 0.15.2 (2026-08-17) - Right-click a portal layer in the Layers panel for Add with full attributes: a second copy of the layer with a working attribute table (QGIS itself has no attribute table for tile layers, which is why the stock menu entry is greyed out). 0.15.1 (2026-08-17) - Opening a portal map now lands on the map's saved viewport instead of zooming out to the whole world. 0.15.0 (2026-08-17) - Private and organization layers open as real feature layers with working attribute tables (needs portal 0.9.28+): private tables now load, and every spatial portal layer gains a right-click Add with full attributes. 0.14.0 (2026-08-16) - Maps now appear in the Browser and search (0.13.0 filtered them out); Open map toolbar button; share with specific groups; GratisGIS actions on the Layers panel right-click; publish several layers as one data layer item. 0.13.0 (2026-08-16) - Open a portal map in QGIS with its styling; published maps keep QGIS symbology; drag a layer onto My Content to publish; sharing from the Browser; Processing algorithms for batch publish and clone; hover cards. 0.12.0 (2026-08-16) - GratisGIS brand icon and a custom toolbar icon set in the portal's palette. 0.11.0 (2026-08-15) - Opening a project with a portal raster no longer freezes QGIS: all portal rasters now draw as map tiles (needs GratisGIS portal 0.9.27+), and scripts/repair_project.py fixes projects saved by older versions. Signing in or out now also applies to layers already on the canvas. 0.9.x - sign-out fixes (layers stopped drawing, credentials cleared properly), safer clone overwrite, split-feature sync fix, publish and search extracted and tested. 0.2.0 - first zip that installs on stock QGIS; background tasks with progress and cancel; private layers render via a portal API key. Full history in CHANGELOG.md.
