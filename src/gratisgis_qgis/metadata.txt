Browse portal items from the QGIS Browser panel, search the portal, drag data layers and maps to the canvas, publish vector layers as portal data_layer items, publish PMTiles / GeoTIFF / MBTiles as tile_layer items, push QGIS edits back to portal-backed layers, clone layers for offline use, and publish the current QGIS project as a portal map. Auth is OAuth + PKCE against the portal's Keycloak realm.
